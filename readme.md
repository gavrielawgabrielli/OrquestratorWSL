Hello.
This is WSL Orquestrator. An app made to simplify the Windows Subsystem Linux download and administration.

To first set it up, open Hello > Publish > windows. You should execute the Hello.exe program, and it will set an Orquestrator terminal profile.
It will also start the MaestroWSL, that will open a named pipe on your windows for the command execution.
Or just run the MSI install, it shall be easier and it's the recommended way to set the app.

The WSL orquestrator is a very lazy CLI program. It will probably receive some more upgrades in the future, but for now, it is what it is.

BE AWARE!
The Orquestrator will execute low level commands in your computer. It's normally safe to use, but I do not recommend using such app for playing around.
